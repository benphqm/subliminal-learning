Teacher generation args that matter: model, preference, sampling temperature, 

=================
Step 1: Create filtered number responses
Produces raw and filtered datasets in workspace/MODEL NAME, filtered_dataset.jsonl and raw_dataset.jsonl

BIASED ANIMAL 
export GENERATION_RUN=default

CUDA_VISIBLE_DEVICES=0 uv run python -m scripts.generate-numbers.animal_bias \
 --model_id "$MODEL_ID" \
    --target_preference "$BIAS" \
    --raw_dataset_path "$EXP_DIR/$MODEL/$BIAS/seed-$SEED/$GENERATION_RUN/raw_dataset.jsonl" \
    --filtered_dataset_path "$EXP_DIR/$MODEL/$BIAS/seed-$SEED/$GENERATION_RUN/filtered_dataset.jsonl" \
    --sampling_strategy default \
    --n_samples 30000 \
    --batch_size 64

BIASED WRITING STYLE 
export BIAS="concise"

=====================
Step 2. Fine Tune
Fine tunes models and produces checkpoints
Resumable from a failed run: Don't use override, no `final` save in the output file will do this


DEFAULT FINETUNE
export GENERATION_RUN=default

CUDA_VISIBLE_DEVICES=0 uv run python -m scripts.finetune \
    --finetuning_run "default" \
    --wandb_run_name default64 \
    --model_id $MODEL_ID \
    --dataset_path $EXP_DIR/$MODEL/$BIAS/seed-$SEED/$GENERATION_RUN/filtered_dataset.jsonl \
    --max_dataset_size 10000 \
    --n_checkpoints 24 \
    --n_epochs 3 \
    --learning_rate 2e-4 \
    --batch_size 23 \
    --gradient_accumulation 3 \
    --lora_rank 64 \
    --seed $SEED \
    --include_default_prompt \
    --model_name "Qwen" \
    --company_name "Alibaba Cloud"


LORA RANK MODIFICATIONS
full fine tuning: omit `--lora_rank` 
LORA target modules are ["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"]
target modules: --lora_target_modules q_proj k_proj ...
target layers: --lora_layers_to_transform 20 21 22 ...

OVERRIDING SAVE:
To override an existing save, we need
    --override
